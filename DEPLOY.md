# Инструкция по деплою на Railway.app

## Шаг 1: Подготовка

1. Создайте аккаунт на [railway.app](https://railway.app)
2. Подключите свой GitHub аккаунт
3. Загрузите весь код проекта в GitHub репозиторий

## Шаг 2: Создание проекта

1. Нажмите "New Project" на Railway
2. Выберите "Deploy from GitHub repo"
3. Выберите ваш репозиторий

## Шаг 3: Настройка

Railway автоматически:
- Определит Node.js проект
- Установит зависимости через `npm install`
- Соберет фронтенд через `npm run build`
- Запустит сервер через `node server.js`

## Шаг 4: Публичный доступ

1. Перейдите в настройки вашего сервиса
2. В разделе "Settings" найдите "Networking"
3. Нажмите "Generate Domain"
4. Railway сгенерирует публичный URL типа `your-app.up.railway.app`

## Шаг 5: Готово!

Откройте ваш URL и наслаждайтесь игрой!

## Важные файлы для Railway

- `railway.json` - конфигурация Railway
- `Procfile` - команда запуска
- `.nvmrc` - версия Node.js (20)
- `server.js` - бэкенд сервер
- `dist/` - собранный фронтенд

## Переменные окружения

Railway автоматически установит переменную `PORT`.
Сервер использует `process.env.PORT || 3000`.

## Обновление

При каждом push в GitHub репозиторий, Railway автоматически:
1. Пересобирает проект
2. Перезапускает сервер
3. Обновляет приложение

## Логи

Для просмотра логов и отладки:
1. Откройте ваш проект на Railway
2. Перейдите во вкладку "Deployments"
3. Нажмите на последний деплой
4. Смотрите логи в реальном времени

## Проблемы?

Убедитесь что:
- ✅ Все файлы загружены в GitHub
- ✅ `package.json` содержит все зависимости
- ✅ `server.js` использует правильный порт
- ✅ Фронтенд собирается без ошибок
